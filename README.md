\# SkinCare AI



SkinCare AI is an AI-assisted skincare web application that helps users explore visible skin concerns, estimate skin type, and discover related skincare products.



\## Features



\- Upload a face photo for AI-based observations

\- Estimate skin type

\- Explore visible skin concerns

\- Get product suggestions from the available product catalog

\- Browse products and use shopping features

\- Compare progress photos

\- Android APK version of the application



\## Technologies Used



\- Python

\- Flask

\- HTML, CSS, JavaScript

\- Gemini API

\- OpenCV

\- Product catalog using CSV

\- Android Studio for APK packaging



\## Setup Instructions



1\. Install Python on your computer.

2\. Open a terminal in the project folder.

3\. Install the required packages:



&#x20;  pip install -r requirements.txt



4\. Create a .env file in the project folder and add your Gemini API key:



&#x20;  GEMINI\_API\_KEY=your\_api\_key\_here



5\. Run the application:



&#x20;  python app.py



6\. Open the local URL shown in the terminal.



\## Important Note



SkinCare AI provides experimental visual observations and general product suggestions. It is not a medical diagnosis or a replacement for professional medical advice.



\## Security



Never upload your actual .env file or API key to GitHub.
